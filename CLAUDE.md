# Banquetes Consuelo C: WordPress website

Rebuild of <https://consueloc.com> from scratch.

## Project direction

- Block theme (FSE) + WooCommerce.
- File structure modeled on <https://github.com/wpshout/modern-wp-fast-track>.
- Hosted on Cloudways; code deploys via Git. Plugins are still updated from WP admin, so Git must not fight plugin updates.

## Agent skills

### Issue tracker

GitHub Issues on `consuelo-c/wp-website` via `gh`. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
